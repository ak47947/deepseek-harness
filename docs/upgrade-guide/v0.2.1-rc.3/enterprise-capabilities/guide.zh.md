# 企业 profile 保留标准功能

[English](guide.md) | 中文

## 变更

企业登录不再禁用产品分析、反馈日志、匿名身份上报、插件管理及市场、运行时自修改或搜索。这些能力沿用标准配置及凭证要求，包括收集地址。桌面端同时提供随包包管理器、命令安装及第三方插件恢复入口。发布地址接受任意显式配置的 HTTPS 主机。

账号准备会识别完整的旧企业限制配置，移除其生成的禁用项和预设覆盖。企业认证、模型下发、账号目录和历史数据保留。之后的个人插件和预设选择在重复登录时保留。

## 迁移

1. 完全退出桌面端，安装更新后的企业应用，再使用原账号登录。账号准备会在启动 Host 前迁移旧限制。
2. 确认侧栏出现“插件”并可打开管理页面。在 macOS 的应用菜单中检查“管理 dsh 命令…”入口，或在 Windows 中检查对应菜单操作。
3. 如需保留个人停用选择，在迁移后将账号 `profiles/desktop/cordis.patch.yml` 中相应条目设为 `disabled: true`。例如，`product-analytics` 控制产品分析。重启并确认选择仍保留；遥测地址参见[收集策略](../../../../packages/client/product-analytics/README.zh.md)。
