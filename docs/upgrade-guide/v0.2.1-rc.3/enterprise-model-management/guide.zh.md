# 企业模型与未分配账号

[English](guide.md) | 中文

## 变更

已认证成员没有可用的个人分配或默认模型时，`GET /v1/session` 返回 HTTP 200 和 `provisioning: null`，替代 HTTP 409。Desktop 可以启动并允许自行配置模型。非空模型下发保留已有字段。

模型管理支持上架、下架和唯一默认模型。下架默认模型会清除默认设置。已有配置包含多个模型时，未分配成员仅收到其中的默认模型。个人分配模型下架后保留选择，但重新上架前停止下发。

## 迁移

1. 同时更新企业后台和 Desktop。自定义 `EnterpriseSession` 调用方须先处理空模型下发，再读取供应商字段；缺失字段仍为无效输入。
2. 正常启动后台。增量迁移保留加密配置和分配，已有记录设为已上架，无需手动修改数据库。
3. 在**模型管理**中选择已上架的默认模型，或不指定默认模型。已有配置包含多个模型时，在**编辑模型 → 默认模型**中选择其中的默认模型。在**用户管理 → 分配模型**中维护个人分配。
4. 确认新建的未分配成员仅收到选定默认模型。清除默认模型后，确认该成员仍可登录，并在**设置 → 模型**中添加个人提供方。
